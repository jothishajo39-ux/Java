# Tic-Tac-Toe (Java Swing)

A simple 2-player Tic-Tac-Toe game built with Java Swing.

## Features
- 3x3 grid GUI, click to play
- Turn tracking (Player X / Player O)
- Win detection (rows, columns, diagonals)
- Draw detection
- Restart Game button

## Requirements
- Java JDK 8 or above installed
- Check with: `java -version`

## How to Run

1. Clone this repository

   git clone <your-repo-url>

   cd <repo-folder>

2. Compile the code

   javac TicTacToe.java

3. Run the game

   java TicTacToe

A game window will open. Click any cell to place X or O, turns alternate automatically, and the winner (or draw) is shown at the top. Click **Restart Game** to play again.
